🎯 Цель проекта

Разработка консольного скрипта и веб-интерфейса для ведения непрерывного диалога с нейросетями через API AllTokens с возможностью переключения системных промптов под разные задачи.

Ключевые задачи:

  • Подключение к OpenAI-совместимому API (https://alltokens.ru/api/v1)
  • Выбор модели из фиксированного списка (6 моделей)
  • Сохранение контекста переписки между запросами
  • Потоковый вывод ответов в реальном времени (стриминг)
  • Три готовые роли: анализ текста, структура кода, планирование
  • Настройка температуры через слайдер (0.0–2.0)
  • Два интерфейса: терминал и веб

🔧 Как это работает

1. Пользователь выбирает вкладку роли → «Использовать эту роль»
2. prompts.py парсит .md файл → извлекает JSON из <code> блока
3. apply_role() подставляет system-промпт в messages[0]
4. Пользователь вводит запрос → st.chat_input
5. OpenAI client.chat.completions.create(stream=True)
6. Чанки выводятся через st.empty() посимвольно
7. Полный ответ сохраняется в session_state.messages

Ключевые модули:

  • prompts.py — load_all(), regex-парсинг <code>
  • app.py — UI, session_state, стриминг, обработка ошибок API
  • chat.py — консольная версия с тем же функционалом
