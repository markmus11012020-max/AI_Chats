Мультимодельный чат с LLM через AllTokens API

Консольный клиент и веб-интерфейс на Streamlit с поддержкой стриминга,
контекста диалога и 6 нейросетей.

Python 3.8+ OpenAI SDK Streamlit Streaming AllTokens.ru

🎯 Цель проекта

Разработка консольного скрипта и веб-интерфейса для ведения непрерывного диалога с нейросетями через API AllTokens.

Ключевые задачи:

  • Подключение к OpenAI-совместимому API (https://alltokens.ru/api/v1)
  • Выбор модели из фиксированного списка
  • Сохранение контекста переписки
  • Потоковый вывод ответов в реальном времени
  • Два интерфейса: терминал и веб

⚡ Возможности

💬 Контекстный диалог

История сообщений сохраняется между запросами — ИИ помнит весь разговор.

🌊 Стриминг

Ответы появляются посимвольно в реальном времени — без ожидания полной генерации.

🎛 6 моделей

Cohere, AllTokens Pareto, MiniMax M3, Gemini Flash, GPT-OSS, Claude Haiku.

🖥 Два UI

Удобный консольный скрипт chat.py и веб-интерфейс app.py.

🖼 Streamlit UI

Веб-интерфейс на Streamlit

  • st.chat_input + st.chat_message
  • История и выбор модели в st.session_state
  • Потоковый рендер через st.empty()
  • Боковая панель с настройками
  • Кнопка очистки диалога

🤖 Ответы моделей

Пример работы

Модель Claude Haiku 4.5 отвечает на вопрос пользователя с учётом контекста и системного промпта «Отвечай кратко и по делу».

Параметры запроса:
  • model: anthropic/claude-haiku-4.5
  • stream: true
  • messages: [system + user + assistant...]
