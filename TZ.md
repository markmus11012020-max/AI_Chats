Техническое Задание (ТЗ): Модуль Chat Completions с контекстом и стримингом (OpenAI SDK)
1. Цель проектаРазработать консольный скрипт на Python для ведения непрерывного диалога с нейросетями через API AllTokens. 
Модуль должен сохранять историю сообщений, поддерживать выбор модели и выводить ответы в режиме реального времени (стриминг).
2. Технические требованияЯзык: Python 3.8+
Зависимости: Официальный пакет openai (pip install openai).Архитектура: 1 файл, отсутствие лишней структуры.
3. Требования к API и инициализацииБазовый URL: https://alltokens.ru
Авторизация: Инициализация клиента OpenAI(api_key=API_KEY, base_url=BASE_URL).
Эндпоинт: Использование стандартного метода client.chat.completions.create.
4. Спецификация моделей
В интерфейсе должен быть реализован выбор строго из следующих моделей (названия не менять):
cohere/north-mini-code:free
alltokens/pareto-code
minimax/minimax-m3
google/gemini-3-flash-preview
openai/gpt-oss-20b:free
anthropic/claude-haiku-4.5
5. Функциональные требованияВыбор модели: Интерактивное меню при старте скрипта.
Режим диалога (Контекст): Скрипт хранит массив messages. Каждый новый запрос пользователя и полный ответ ИИ добавляются в историю.Системный промпт: Первым элементом в историю всегда передается: {"role": "system", "content": "Отвечай кратко и по делу."}.Потоковый вывод (Стриминг):В методе создания чата должен быть передан параметр stream=True.Ответ от нейросети должен выводиться в консоль посимвольно/пословесно по мере генерации, а не дожидаться полного ответа.Управление: Чат работает в бесконечном цикле. Выход из программы по команде exit.
