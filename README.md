# 💬 AllTokens Chat

Streamlit-чат с LLM через прокси [alltokens.ru](https://alltokens.ru) (OpenAI-совместимый API). Поддерживает несколько ролей-промптов и настройку температуры.

## Структура слайдов
1. Титульный — AllTokens Chat
2. Цель проекта и задачи
3. Возможности (контекст, стриминг, роли, температура, модели, UI)
4. Система ролей (Summary / Code / Planning)
5. Streamlit UI — общий вид (скрин1.png)
6. Боковая панель настроек (скрин2.png)
7. Стриминг ответа модели (скрин3.png)
8. Сравнение моделей (скриншоты из `screenshots/`)
9. Структура проекта
10. Поток данных (как работает)
11. Итог

## Скриншоты
- `скрин1.png` — общий вид Streamlit UI с вкладками ролей
- `скрин2.png` — боковая панель с моделью и температурой
- `скрин3.png` — стриминг ответа модели в реальном времени
- `screenshots/` — дополнительные примеры ответов разных LLM

## Запуск
Открыть `presentation.html` в браузере (двойной клик).

## ✨ Возможности

- 💬 Потоковый чат с LLM (streaming)
- 🎭 **4 режима чата** — переключаются через вкладки:
  - 💬 **Базовый чат (ТЗ)** — системный промпт из исходного ТЗ: «Отвечай кратко и по делу.»
  - 📝 **Структурирование и анализ текста / Summary Prompt** — резюме, анализ, ключевые тезисы
  - 💻 **Генерация структуры кода / Code structure** — архитектура проекта, модули, паттерны
  - 📋 **Планирование задач проекта / Task Planning Prompt** — декомпозиция задач, оценка рисков, таймлайн
- 🌡️ **Слайдер температуры** (0.0–2.0) — от точных до креативных ответов
- 🗑️ Очистка чата с сохранением активной роли
- 🔌 Выбор модели из списка


## 🚀 Установка

1. Клонировать репозиторий:
   ```bash
   git clone <repo-url>
   cd <repo-folder>
   ```

2. Создать виртуальное окружение и активировать:
   ```bash
   python -m venv venv
   venv\Scripts\activate        # Windows
   source venv/bin/activate     # Linux/macOS
   ```

3. Установить зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Создать `.env` файл в корне:
   ```env
   ALLTOKENS_API_KEY=sk-at-ваш_ключ
   ALLTOKENS_BASE_URL=https://alltokens.ru/api/v1
   ```

## ▶️ Запуск

### Веб-интерфейс (Streamlit)
```bash
python run_bot.py
```
или
```bash
streamlit run app.py
```
Откроется в браузере: http://localhost:8501

### Консольная версия
```bash
python chat.py
```

## 🎭 Использование ролей

1. В верхней части интерфейса выберите вкладку нужной роли.
2. Нажмите **✅ Использовать эту роль** — системный промпт подставится автоматически.
3. Отправьте запрос — модель ответит в выбранной роли.
4. Активная роль отмечена плашкой `✅ Активная роль: ...`.

Каждая роль содержит подробное описание в expander'е **ℹ️ Описание роли**.

## 🌡️ Температура

В боковой панели (`⚙️ Настройки`) слайдер температуры:

| Значение | Поведение |
|----------|-----------|
| 0.0      | Максимально точные, детерминированные ответы |
| 0.7      | Баланс (по умолчанию) |
| 1.2+     | Креативные, разнообразные ответы |

Значение передаётся в `temperature` каждого запроса к API.

## 🤖 Доступные модели

- `cohere/north-mini-code:free`
- `alltokens/pareto-code`
- `minimax/minimax-m3`
- `google/gemini-3-flash-preview`
- `openai/gpt-oss-20b:free`
- `anthropic/claude-haiku-4.5`

Список моделей редактируется в `app.py` → константа `MODELS`.
